# FlexSearch 搜索功能实现文档

## 概述

本文档描述了已实现的 FlexSearch 文章搜索功能，包括实现细节、使用方法和注意事项。

## 实现文件

### 1. 核心搜索逻辑
**文件**: `composables/useSearch.ts`

这是搜索功能的核心 composable，提供以下功能：
- FlexSearch 索引初始化
- 文档添加和批量索引
- 搜索查询执行
- 索引管理

**主要特性**:
- 支持中文搜索（使用 `latin:simplified` 字符集）
- 前向分词（`tokenize: 'forward'`）对中文更友好
- 内存优化的搜索配置（`profile: 'memory'`）
- 支持标题、描述、标签和分类的多字段搜索

### 2. 搜索组件
**文件**: `components/SearchModal.vue`

提供完整的用户界面，包括：
- 搜索弹窗组件
- 键盘快捷键支持（Ctrl/Cmd + K）
- 实时搜索建议
- 搜索结果高亮显示
- 键盘导航（↑↓ 选择，Enter 确认）

**UI 特性**:
- 响应式设计
- 暗色/亮色主题支持
- 搜索结果分类和标签显示
- 无结果提示
- 加载状态显示

### 3. API 端点
**文件**: `server/api/search.index.get.ts`

服务端 API，用于获取所有文章元数据：
- 查询所有 `@nuxt/content` 文档
- 过滤和转换为搜索文档格式
- 返回统一的文章列表

### 4. 类型定义
**文件**: `types/search.d.ts`

FlexSearch 的 TypeScript 类型声明，补充了原包缺少的类型定义。

### 5. 导航集成
**文件**: `layouts/default.vue`

在导航栏中集成搜索功能：
- 添加搜索按钮
- 客户端加载搜索索引
- 自动初始化搜索数据

## 使用方法

### 启动搜索

1. **键盘快捷键**: 按 `Ctrl/Cmd + K` 打开搜索弹窗
2. **点击按钮**: 点击导航栏的搜索图标

### 搜索功能

1. **输入关键词**: 实时搜索文章标题、描述、标签
2. **导航结果**: 使用 `↑↓` 键选择搜索结果
3. **打开文章**: 按 `Enter` 键或点击结果跳转到文章
4. **关闭搜索**: 按 `Esc` 键或点击外部区域

### 支持的搜索类型

- **标题搜索**: 匹配文章标题
- **描述搜索**: 匹配文章描述
- **标签搜索**: 匹配文章标签
- **分类搜索**: 匹配文章分类
- **中文搜索**: 支持中文关键词搜索
- **英文搜索**: 支持英文关键词搜索

## FlexSearch 配置说明

### 当前配置

```typescript
{
  profile: 'memory',           // 内存优化配置
  charset: 'latin:simplified', // 支持简体中文
  tokenize: 'forward',         // 前向分词
  resolution: 9,               // 高精度搜索
  optimize: true,              // 启用优化
  threshold: 1,                // 相关性阈值
  minlength: 1,                // 最小匹配长度
}
```

### 性能考虑

- **内存模式**: 适合客户端搜索，内存占用适中
- **高精度**: 分辨率设置为 9，提供更准确的搜索结果
- **优化选项**: 启用内部优化，提升搜索速度

## 注意事项

### Node.js 版本兼容性

**问题**: Node.js 18.20.8 与 Nuxt CLI 3.34.0 存在兼容性问题

**错误信息**:
```
SyntaxError: The requested module 'node:util' does not provide an export named 'styleText'
```

**解决方案**:
1. 升级 Node.js 到 20.x 或更高版本
2. 或者使用生产构建（`pnpm run generate`）进行测试

### 中文搜索优化

当前配置对中文搜索进行了优化：
- 使用 `latin:simplified` 字符集
- 前向分词策略
- 最小匹配长度为 1

### 性能优化建议

1. **索引大小**: 文章数量较多时，考虑分批加载索引
2. **搜索防抖**: 已实现 300ms 防抖，避免频繁搜索
3. **结果限制**: 默认返回 20 个结果，避免过多数据
