# FlexSearch 搜索功能 - 快速开始指南

## 快速开始

### 1. 激活搜索

有两种方式打开搜索功能：

- **键盘快捷键**: 按 `Ctrl + K` (Windows/Linux) 或 `Cmd + K` (Mac)
- **点击按钮**: 点击导航栏右侧的搜索图标 🔍

### 2. 使用搜索

1. 在搜索框中输入关键词
2. 查看实时搜索结果
3. 使用 `↑↓` 方向键选择结果
4. 按 `Enter` 键打开选中的文章
5. 按 `Esc` 键关闭搜索弹窗

### 3. 支持的搜索类型

你可以搜索以下内容：

- **文章标题**: "Vue 3"、"TypeScript"
- **文章描述**: "深入理解"、"入门教程"
- **标签**: "GIS"、"前端框架"
- **分类**: "vue"、"frontend"

### 4. 中英文搜索

搜索功能完全支持中英文：

- 英文: "composition"、"mapbox"
- 中文: "详解"、"教程"
- 混合: "Vue API"、"GIS 教程"

## 功能特点

### ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 打开/关闭搜索 |
| `↑` | 上一个结果 |
| `↓` | 下一个结果 |
| `Enter` | 打开选中结果 |
| `Esc` | 关闭搜索 |

### 🎨 界面特性

- **实时搜索**: 输入即搜索，无需点击按钮
- **结果高亮**: 匹配的关键词会高亮显示
- **分类标签**: 每个结果显示文章分类和标签
- **响应式设计**: 支持桌面和移动设备

### 🔍 搜索算法

- **智能匹配**: 支持部分匹配和模糊搜索
- **多字段**: 同时搜索标题、描述、标签、分类
- **高性能**: 搜索响应时间 < 1ms

## 常见问题

### Q: 搜索不到某些文章？

A: 可能的原因：
- 文章尚未被索引（刷新页面重试）
- 关键词拼写错误
- 关键词太短（尝试使用更长的关键词）

### Q: 中文搜索不工作？

A: 确保使用正确的中文关键词：
- ✅ "详解"、"教程"、"深入"
- ❌ "好"、"优秀"（避免使用常见词）

### Q: 搜索速度慢？

A: 正常情况下搜索应该很快（<1ms）：
- 如果较慢，可能是网络问题
- 尝试刷新页面重新加载索引

### Q: 如何关闭搜索？

A: 有三种方式：
- 按 `Esc` 键
- 点击弹窗外部区域
- 点击右上角的 × 按钮
