# Open Graph 社交分享图片说明

## 位置
`public/og-image.png` 或 `public/og-image.jpg`

## 推荐尺寸
- **宽度**: 1200px
- **高度**: 630px
- **比例**: 1.91:1

## 设计建议
1. **品牌标识**: 包含网站名称 "wanGISen" 或个人头像
2. **简洁明了**: 使用清晰的标题和简短描述
3. **视觉吸引力**: 使用与网站主题一致的配色方案
4. **文字可读性**: 确保文字在社交平台的小尺寸预览中清晰可见
5. **留白充足**: 避免内容过于拥挤

## 示例内容
```
┌─────────────────────────────────────────┐
│                                         │

│                                         │
```

## 验证工具
创建图片后，可使用以下工具验证：
- Facebook Sharing Debugger: https://developers.facebook.com/tools/debug/
- Twitter Card Validator: https://cards-dev.twitter.com/validator
- LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/
